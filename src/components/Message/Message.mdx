## Optional dismissal

Set `dismissible` to show a close action. The component hides itself when uncontrolled and emits `onClose` and `onVisibilityChange` for consumers that manage visibility.
The example below is interactive: activate the visible close-circle button to remove the message.

## Accessibility and Web Components

- Danger and warning messages use `role="alert"`; danger uses assertive announcements.
- Other messages use `role="status"` with polite announcements.
- Use `<hans-message>` outside React. Pass complex `title` and `message` values as element properties and listen for `close` or `visibilitychange` events.
