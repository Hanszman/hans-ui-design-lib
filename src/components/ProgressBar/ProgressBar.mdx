# Progress Bar

Accessible determinate progress for numeric or ordinal values. Always pair semantic colors with a visible `valueLabel` when color represents a domain state.

## Loading

Use `loading` while the value is unresolved. The determinate semantics are withheld until a real value is available, and an accessible skeleton is rendered instead.

<Canvas of={Stories.Loading} />

The Web Component is available as `<hans-progress-bar>`. Use props: `value`, `min`, `max`, `label`, `value-label`, `progress-color`, `progress-size`, `show-value` and `loading`.
