The **DatePicker** component supports `date`, `datetime` and `time` selection while reusing the Hans input, icons and popup patterns.

## Usage

```tsx
import { HansDatePicker } from 'hans-ui-design-lib';

export const Example = () => (
  <HansDatePicker
    label="Start date"
    pickerType="datetime"
    inputColor="primary"
    calendarColor="secondary"
    defaultValue="2026-03-13T14:30"
  />
);
```

## Required fields

Set `required` to append the standard asterisk to the label and apply the native
constraint to the underlying date, datetime or time input. Do not include `*` in
the label text supplied by the consumer.

<Canvas of={HansDatePickerStories.Required} />

```html
<hans-date-picker label="Start date" required></hans-date-picker>
```

## Date

Use `pickerType="date"` for a fast calendar-only selection flow.

<Canvas of={HansDatePickerStories.DateOnly} />

## Display format

Dates use `DD/MM/YYYY` by default. Set `dateFormat="MM/DD/YYYY"` for locales
that display the month before the day. The selected value remains the stable
ISO form `YYYY-MM-DD`, regardless of the visual format.

<Canvas of={HansDatePickerStories.MonthDayYear} />

```html
<hans-date-picker
  label="Start date"
  date-format="MM/DD/YYYY"
></hans-date-picker>
```

## Calendar locale

Use `locale="en-us"`, `locale="pt-br"` or `locale="es-es"` to localize month
names, weekday abbreviations, calendar actions and accessible navigation labels.
The default is `en-us`. Explicit `clearLabel`, `todayLabel` and `applyLabel`
values continue to override the localized defaults.

<Canvas of={HansDatePickerStories.LocalizedCalendars} />

```html
<hans-date-picker locale="pt-br"></hans-date-picker>
```

## DateTime

Use `pickerType="datetime"` when a date and a masked time should be selected together.

## Time

Use `pickerType="time"` for masked time selection only. Set `timePrecision="second"` to include seconds.

<Canvas of={HansDatePickerStories.TimeOnly} />

## Manual Typing

Set `allowInputTyping` to let users type `date` and `datetime` values manually while keeping the same validation rules.

<Canvas of={HansDatePickerStories.ManualTyping} />

## Surface Overrides

Use `popupBackgroundColor` to style the outer popup shell when needed and `panelBackgroundColor` to control the calendar surface itself. In dark or modal-like contexts, prefer overriding the panel surface directly so the calendar background stays aligned with the surrounding theme.
