The **Carousel** component displays image galleries with previous and next
navigation, progress indicators, loading skeletons and an empty state.
Each slide can optionally render a title and description above the image, using
the same visual direction as the image layout from the card component.

## Usage

```tsx
import { HansCarousel } from 'hans-ui-design-lib';

const items = [
  {
    id: 'cover-1',
    title: 'Campaign',
    description: 'A highlighted hero image.',
    imageSrc: 'https://example.com/cover.jpg',
    imageAlt: 'Campaign cover',
  },
];

export const Example = () => (
  <HansCarousel
    items={items}
    visibleItemsCount={1}
    carouselColor="primary"
    carouselVariant="outline"
  />
);
```

## Open Image On Click

Enable `openImageOnClick` to let visitors open any currently visible slide's
full image in a new browser tab. Every visible slide becomes interactive
(when `visibleItemsCount` is 2 or 3, all of them — not only the active/
centered one).

This is opt-in and defaults to `false`, so existing carousels keep their
current behavior unless you explicitly enable it.

When enabled, each visible slide's image:

- switches its accessible role from `img` to `button`.
- exposes a descriptive `aria-label`, controlled by `openImageLabel`
  (defaults to `"Open image in new tab"`).
- becomes focusable (`tabIndex={0}`) and is operable with both mouse clicks
  and the keyboard (`Enter` or `Space`).
- opens `item.imageSrc` with `window.open(imageSrc, '_blank', 'noopener,noreferrer')`.
- gets a `hans-carousel-image-clickable` class that only changes the cursor
  to a pointer, with no other visual change.
